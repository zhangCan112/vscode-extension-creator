# 图可视化（关系图 / 依赖图 / 策略图）

做 Webview 图（节点-连线）前先读本文。核心原则：**布局跟着图语义走；编码只花在固定小集合上；信息按需披露**。图"乱"的根源几乎总是三条之一：布局与语义错配、全量标签、聚焦时无关元素仍占画面。

参考实现（本 repo）：`wuxia-relations/`（对等关系网）、`module-policy-graph/`（分层 DAG + 声明匹配 + 100 节点压测）。

## 第一步：判断图语义，选布局

| 图语义 | 布局 | 理由 |
|---|---|---|
| 对等关系网（人物/社交，无固定方向） | 力导向 fcose（质量优于内置 cose） | 簇自然浮现 |
| 依赖 / 分层 DAG（模块依赖、调用链） | dagre 分层 TB（容器宽 < 高时改 LR，如侧栏 WebviewView） | 位置即方向；环 = 向上指的边，一眼可见 |
| 双向声明匹配（policy SEND/RECEIVE、授权对齐） | dagre TB + 数据流方向箭头 | 语义重点是"对齐没有"，不是拓扑 |
| >300 节点 | tier 聚合成可折叠超节点，或邻接矩阵混合 | 节点链接图的可读上限 |

DAG 一律不用力导向——方向信息会被随机位置淹没。

平行边与环的处理：

- 同一对节点的多种通道类型**保留平行边**（bezier 自动散开），不合并——类型集合固定时平行边本身可读
- 需要一键定位环时：DFS 找出所有环上边统一强调色高亮（+ 信息栏列出涉及模块），比逐边标注干净；超大强连通分量可折叠为超节点

## 编码规则

1. **固定且少（≤7）的消息/关系类型 → 颜色 × 线型 × 箭头形状三重冗余**（缩小/色弱下仍可分辨）。类型集合不固定或 >10 种时只编码颜色，其余进悬停详情。起步色板（明套/暗套）：`#1565c0 #c62828 #2e7d32 #8e24aa #ef6c00` / `#64b5f6 #e57373 #81c784 #ba68c8 #ffb74d`，需第 6/7 色补 `#00838f`/`#4dd0e1`、`#5d4037`/`#bcaaa4`
2. **每类元素只占一个颜色通道**：边用类型色 → 节点用中性填充 + 边框色表达分类；节点和边各挂一套彩色图例必然打架
3. 数值维度（度数/耦合度）→ 大小映射：`mapData(degree, 0, max, 11, 14)` 映射节点字号，枢纽自然突出
4. 状态用线型变体：虚线 = 带状态；**未对齐/悬空 = 淡显 + 无箭头 + 常显琥珀色小标签**（低频异常才允许常显标签）
5. 箭头语义全图唯一：数据流方向**或**依赖方向，二选一，图例写明——混用必困惑。天然双向的类型（如 rpc 请求-响应）只画发起方向的单向边，回流不画边、细节进悬停/详情面板

## 渐进披露（对付"乱"的最强手段）

- **三级聚焦**：总览 → 实体（1 跳邻域）→ 单条关系；面包屑逐级回退，空白点击回总览
- **聚焦 = 子图隔离**：无关元素 `display:none` 离场 + 只对子图重排（宽松间距），**不是淡化占位**——100 节点时淡化照样乱
- 悬停 = 临时高亮邻域（不跳视口）；点击 = 锁定聚焦（跳视口 + 详情面板）；两态互斥（有锁定态时悬停不生效）
- **边标签永不常显**：悬停边 / 聚焦时才出现
- 语义缩放：`min-zoomed-font-size: 6`——缩到全图只剩结构骨架，放大才出文字
- 实体详情放侧面板（如 SEND/RECEIVE 清单 + ✓/✗ 匹配态），不往画布上堆；面板条目可点 → 下钻到单条关系

## 规模阶梯

| 节点 | 策略 |
|---|---|
| ≤60 | 布局随意，把交互做足 |
| 60~300 | 边默认 35% 透明度（强调态恢复 1）；布局参数收紧（rankSep 60 / nodeSep 35）、关动画；靠下钻阅读，不指望全图可读 |
| >300 | 聚合折叠 + 矩阵混合，别硬画 |

## 双向声明匹配（policy 类图特有）

- 通道成立 = 双方声明对齐（A.send + B.receive 三元组 join）；单边声明产出**悬空发送 / 悬空订阅**，编码见上
- 匹配在宿主侧算好，webview 只消费状态——不在画布侧算业务语义
- 循环检测只算已对齐通道（悬空边不承载真实数据流）；配"仅看悬空"一键筛出问题声明

## 落地要点

- 确定性布局（dagre 同输入同输出）→ 从聚焦回总览不漂移；聚焦子图用宽松参数（rankSep 90 / nodeSep 55）单独重排
- 图例 = 可点过滤器（类型/分类显隐），用 class + `display:none`，不删元素
- 拖拽与点击区分：drag 时置标记，吞掉松手后紧随的 tap
- cytoscape 布局扩展（fcose/dagre）不带类型声明时补最小 ambient d.ts（`cytoscape.Ext`）
- 主题色板解析、canvas 吃不到 CSS 变量的处理 → 见 `treeview-webview.md`「主题适配」
